# 🧍‍♂️ RPi WS2812B Body (Interactive LED Human Body)

This repository contains the code for a high school "Natuur, Leven en Technologie" (NLT) project. It provides a web interface to control a WS2812B (NeoPixel) LED strip connected to a Raspberry Pi.

The LEDs were physically mapped to different human organ systems on a display board. By clicking the buttons on the website, the Raspberry Pi lights up the corresponding organs.
